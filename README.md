# AI Product Builder Portfolio

`ningfangtianwai-pixel` 的个人作品集网站，重点展示 AI Agent、业务自动化、企业智能工作流与真实业务验证。

## 本地运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run check
```

## 内容结构

- 首页：定位、成果数字、旗舰项目、其他探索、产品方法、About、Contact
- 项目详情：三个旗舰项目的业务问题、方案、结果与产品链路
- 项目履历：可打印或保存为 PDF 的项目型简历
- GitHub Pages：推送到 `main` 后由 Actions 自动构建部署

## 内容边界

网站只使用已经提供或公开仓库能够验证的信息，不展示虚构客户、收入、Stars、Demo 或技术能力。没有公开地址的项目只展示产品方向，不提供虚假链接。
