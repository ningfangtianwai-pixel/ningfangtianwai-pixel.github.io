# Manny · AI Product Builder Portfolio

`ningfangtianwai-pixel` 的个人作品集网站，重点展示 AI Agent、业务自动化、企业智能工作流与真实业务验证。

## 本地运行

```bash
npm install
npm run dev
```

生产检查与浏览器测试：

```bash
npm run check
npm run test:e2e
```

## 内容结构

- 首页：真实产品界面、成果数字、旗舰项目、产品方法、About、Contact
- 项目详情：三个旗舰项目的 Role、Evidence、产品判断、真实截图与结果
- 交互 Demo：TalentFlow、企业评估与 Project D 的可操作产品流程；示例数据均明确标注
- 项目履历：可打印或保存为 PDF 的项目型简历
- GitHub Pages：推送到 `main` 后由 Actions 自动构建部署

## 内容边界

网站只使用已经提供、在本机实际运行或公开仓库能够验证的信息，不展示虚构客户、收入、Stars 或技术能力。交互 Demo 使用匿名示例数据，并与真实业务数据、正式评估结论和桌面应用本体明确区分。

企业评估公开口径以当前 v0.2 数据契约为准：176 个字段、5 个模块、23 个评估字段与 8 个全局风险闸门。
